A little help tuning

If your instrument is already close: turn on Auto Detect. Pluck one string at a time. The tuner will choose the closest string and tell you whether the note is too low or too high. Keep plucking about once each second while you make small turns.

If you are not sure where to start: tap the string you want to tune. You will hear the note that your string should match. Listen carefully, then adjust your string until it sounds as close as possible. Turn Auto Detect back on to finish with the tuner.

Stop tightening if a string feels unusually tight. Check that you selected the correct instrument, tuning, and string before continuing.
